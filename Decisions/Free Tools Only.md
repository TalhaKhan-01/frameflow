# Free Tools Only

## Context
[[Frameflow]] has no budget. It aims at 1–2 short videos a day for YouTube Shorts and Instagram Reels ([[V1 Scope]]).

## Options
1. Free and local tools only.
2. A small monthly budget for paid APIs (TTS, image generation, stock, posting services).

## Decision
Option 1, decided by Talha on 2026-10-23. Every tool must be free to use **and** licensed for commercial use, because the channel may be monetised.

## Consequences
- Voice, captions and rendering run locally (see [[Tool Candidates]]).
- Scripts are written by Claude through Claude Code inside the Pro plan, or by a local model. The paid Claude API is not used.
- Every asset in a video gets a licence record (source, licence, link).
- Non-commercial models and assets (F5-TTS weights, XTTS-v2) are ruled out.
